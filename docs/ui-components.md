# 界面基础组件约定与检查结果

管理后台统一使用 Ant Design 基础组件，以 theme.ts 的主题配置和 style.css 的业务样式调整外观。不另写 Select、Button、Input、Modal、分页等基础交互组件；确有无法满足的需求，先说明原因、替代方案和影响并获得确认。

## 管理后台

| 区域                                       | 组件                                                | 检查结果                                   |
| ------------------------------------------ | --------------------------------------------------- | ------------------------------------------ |
| 每页条数、项目筛选、状态、皮肤选择         | Select                                              | 分页原生 select 已替换，统一弹层和焦点样式 |
| 导航、反馈卡片入口、操作按钮               | Button                                              | 原生导航与卡片按钮已替换                   |
| 反馈状态、项目启停状态                     | Tag                                                 | 反馈手写标签已替换，保留语义状态色         |
| 登录、初始化、修改密码、项目编辑、处理备注 | Form、Input、Input.Password、Input.TextArea、Switch | 已使用组件库                               |
| 弹窗、抽屉、启停确认                       | Modal、Drawer、Popconfirm                           | 已使用组件库                               |
| 账号菜单、接入代码标签页                   | Dropdown、Tabs                                      | 已使用组件库                               |
| 项目表格、详情元数据、图片预览、复制       | Table、Descriptions、Image、Typography              | 已使用组件库                               |
| 加载、空状态、错误、提示                   | Spin、Empty、Alert、Result、App message             | 已使用组件库                               |
| 页码                                       | Pagination                                          | 已使用组件库                               |

ListPagination 仅组合现有 Pagination 和 Select，负责业务页码及每页条数回调，不实现下拉、键盘导航或分页基础行为。反馈列表卡片、品牌、页面框架是业务展示组合，保留语义布局与 CSS。

## SDK 例外：已确认保留

用户于 2026-10-28 确认：保留 SDK 现有实现，仅将管理后台统一到 Ant Design。SDK 继续通过原生 DOM 和 Shadow DOM 实现以下基础交互：

- 原生 dialog：反馈面板、关闭、Esc、焦点恢复。
- textarea / input：反馈内容与联系方式。
- button：浮动入口、图片添加与删除、提交、重试、完成。
- file input：系统文件选择，与现有图片限制、预览和上传逻辑配合。

SDK 当前不依赖 React，提供 ESM/IIFE 接入，支持 CSP nonce、Shadow DOM 隔离以及多皮肤。直接引入后台 Ant Design 将新增框架运行时和组件样式注入，需要重新验证包体、浮层容器、严格 CSP 与宿主隔离，不能当作纯样式替换。

本次不迁移 SDK 的基础组件。此后如需新增或重写基础组件，仍须先整理必要性、替代方案和影响，取得用户确认后再实施。此次没有新增自行实现的基础组件。
