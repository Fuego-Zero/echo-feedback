# SDK 0.2.0 发布说明

## 新增功能

- SDK 内置简体中文和英文，新增 `locale`、`open({ locale })` 与 `setLocale()`。
- 默认每次打开时优先参考宿主页面语言，其次参考浏览器语言，最后回退简体中文。英文宿主需要固定旧版中文行为时，显式设置 `locale: "zh-CN"`。
- 原地切换语言保留正文、联系方式、图片、焦点、在途请求和结果不明时的重试快照，不改变原幂等键。
- 后台支持中英文；首次自动匹配浏览器，菜单提供简体中文与 English，手动选择后记忆偏好。
- 登录、后台、SDK 和浏览器图标统一使用「对话回响」标识，并修复窄屏预览与项目来源校验提示。

## 升级方式

升级 npm 依赖到 `@echo-feedback/sdk@0.2.0`，或复制更新后后台提供的 `/sdk/0.2.0/echo-feedback.iife.js` 地址。旧 `/sdk/0.1.0/` 保留为兼容入口，随网站提供当前构建，不保证历史内容不变。

宿主语言改变时调用 `setLocale()`；宿主自行控制打开入口时，可在每次 `open({ locale })` 中传入当前语言。不要通过销毁实例重新初始化来切换语言或重试。

## 验证范围

已完成本地 Chromium 中英文、桌面及手机尺寸模拟验收，覆盖初始化、登录、列表、详情、弹窗和七套 SDK 皮肤的明暗、校验、草稿、失败重试与成功状态。`pnpm verify` 和独立 npm 安装包验收是发布门槛；GitHub Actions 结果以实际运行记录为准。

尚未完成手机真机和真实第三方宿主联调，不能将浏览器尺寸模拟视为真机验收。网站镜像部署和 npm 发布由各自工作流确认结果。
