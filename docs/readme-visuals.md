## 来源

- 采集日期：2026-11-02。
- 界面来源：当前仓库构建后的管理后台与真实 SDK，使用 Chromium 和独立的本地演示环境采集。
- 项目、反馈、备注、账号与来源地址：均为专门构造的虚构演示数据。没有读取或展示生产数据库、用户附件与管理员凭据。
- 窄屏画面：390 × 844 的浏览器视口模拟，不代表手机真机结果。
- 首图为 SVG 品牌插画，其中两张对话卡片表达反馈与改进的主题，不表示产品提供用户消息回复功能。

## 更新约定

1. 先构建当前代码，在 `.tmp/` 下创建独立的演示数据目录，使用独立端口，不连接生产服务或真实宿主。
2. 准备虚构的项目与反馈，使用当前后台和 SDK 操作并截图。不得以手绘表单或重写的页面冒充真实界面。
3. 皮肤展示通过 SDK 的 `uiStyle` 与 `theme` 参数切换；语言展示使用 `locale`。不要修改生产样式来适配配图。
4. 在 `.tmp/` 中保留原始截图与拼版过程，将最终静态素材放入本目录的 `assets/readme/`。拼版只调整外围排版、缩放和标题，不改写截图中的产品内容。
5. 检查默认宽度、窄屏下的 README 和图片放大后的清晰度；为新增图片编写有意义的替代文字。
6. 同步配图日期与说明，运行 `pnpm verify`。浏览器截图不能替代真实宿主联调与手机真机验收。
